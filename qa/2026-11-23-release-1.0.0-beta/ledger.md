## Fixes made in this release run
- F7 `crates/eq-parametric/src/lp.rs`, `lib.rs`: a linear-phase kernel that arrives after the 0.5 s wait (an offline render faster than real time) blended in from the delayed signal instead of a step. Found by `latency_changes_do_not_click`, which failed in release only; passes 10/10.
- F8 OpenPluginSDK `native/vst3/OpenPluginVST3.cpp` (and the AAX shell): null host channel pointers stay null when the shell splits a block; before, null + offset crashed pluginval's automation test (1985 parameter changes split the block one sample in, with the sidechain unconnected). New case in `vst3_events_proof` crashed before the fix and passes after.
- F9 OpenPluginSDK `openplugin-targets/src/clap.rs`: CLAP marks a parameter stepped only on a whole-number grid (the LV2 `lv2:integer` rule). Before, 0.1 dB grids were stepped, so a host could round them, and clap-validator failed 12 tests. New unit test.
- F10 OpenPluginSDK `native/aax/OpenPluginAAXParameters.cpp`: a discrete parameter with more than 2048 steps (Rack Modules, a bit mask) is described as continuous; the AAX Validator failed `test.parameters`.
- F11 `src/lib.rs` `aax_ids` (OpGd / OLim / OLmM / OLmS) and `scripts/build.sh --aax-pages`: the AAX carries a page table (`test.page_table.load` failed without one).
- F12 `src/lib.rs` `lv2_uri` = https://opengrid.studio/plugins/openlimiter. The default was the plugin id, not an absolute URI: REAPER loaded the LV2 with no parameters and silent output.
- F13 `.github/workflows/build.yml`: Windows checksum file with a Unix line ending; the static C runtime flag and the UIAutomationCore.DLL allowance for the Windows build.
- SDK test stubs: the C++ proof stubs export the ABI 9 foreign-state functions, so the VST3 and AAX proofs link again (they did not at 0f50066).

## Exceptions
- UIAutomationCore.DLL allowed in the Windows import check (NEW): it is the Windows accessibility library the editor's window code imports, part of Windows, not a runtime to install.
- AAX Validator copy patched in `Tools/DTT/sources/classes/SysInfo.rb` (`.to_s`), as documented in the SDK; Avid's original files are untouched. Without it four `info`/`data_model` tests abort in the tool itself.

## Open findings
- REAPER CLAP suite, random state 1: Headroom and Delay Unit (neither is read by the DSP) changed the render, so that random state did not render the same twice in REAPER. The cause is not found. Default state: 14 renders bit-identical, also with two REAPERs rendering at once; PrecisionEQ linear phase repeats bit-exactly in-process. One earlier run (two suites in parallel, old LV2 build alongside) failed the default-state determinism check with a -6 dB difference that could not be reproduced. Worth a targeted look before 1.0.0 final.
- Unused code warnings in `src/ui/mod.rs` (P_RELEASE_A, P_RELEASE_M, value_text, Ui::unit): existing, not changed.
